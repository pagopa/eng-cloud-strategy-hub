# Copilot Customization

This context names the repository-owned language for instructions, customization assets, and governance used by agents and contributors.

## Language

**Instruction**:
A repository-owned rule set that applies to an agent or a path-scoped task.
_Avoid_: Prompt, policy file

**Customization asset**:
A repository-owned Copilot instruction, prompt, skill, or agent definition.
_Avoid_: Configuration blob

**Validation profile**:
A named set of checks applied to a defined Copilot customization scope.
_Avoid_: Mode, workflow
