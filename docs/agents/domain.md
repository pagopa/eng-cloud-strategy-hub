# Domain Docs

Before exploring, read [`CONTEXT-MAP.md`](../../CONTEXT-MAP.md), the relevant
domain context under `docs/domain/`, and ADRs under `docs/adr/` that affect the
current area. Proceed silently when a referenced document does not exist.

This repository uses the multi-context layout. The map names the Copilot
customization, reusable automation, and Terraform operator tooling contexts.
Use their glossary terms consistently and surface conflicts with existing ADRs.
