# Use a Context Map for the Hub's Knowledge Layout

Status: accepted

The repository uses a context map because its evidence supports three durable domains: Copilot customization, reusable automation, and Terraform operator tooling. Keeping those glossaries separate preserves domain vocabulary while the root map records the relationships between them; the decision is evidenced by `.github/`, `actions/`, `scripts/`, `tools/`, `tests/`, and the repository architecture contract.
